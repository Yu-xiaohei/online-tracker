# PC 状态通知器 — 通知通道方案 v2

> 给负责开发 Windows 托盘软件的 AI：本文档是通知通道部分的完整实现规范（v2，2026-10-16）。
> app 尚未开始开发，以下可直接作为通道模块的需求输入。
> 变更记录：v1 的邮件降级通道已取消；主通道为官方 API 直连，CF 转发器为次级。

## 1. 通道定义

| 层级 | 通道 | 基地址 | 前提条件 |
|---|---|---|---|
| 主 | 官方 Telegram Bot API 直连 | `https://api.telegram.org/` | PC 的 Clash/代理可用 |
| 次级 | Cloudflare Worker 反代 | 用户自建，如 `https://yuno-tg.xxx.workers.dev/<SECRET>/` | 无需梯子 |

VM 端（小于蛋）**无需任何改动**——VM 在海外，直连 Telegram 即可。

## 2. 发送与降级逻辑

所有 Telegram 发送统一走 `SendTelegram(method, params)`：

1. **通道顺序**由「通道模式」配置决定：
   - `自动`（默认）：先官方，失败后转 CF
   - `仅官方直连`：只走官方
   - `仅CF转发`：只走 CF
2. **官方通道**：单次超时 15 秒，最多 2 次。失败情形：连接超时、代理不可达、HTTP 5xx、网络错误 → 记录失败原因。
3. 自动模式下官方失败 → **立即**走 CF 通道（单次超时 15 秒，最多 2 次）。
4. 全部失败 → 返回失败，状态窗口报错，托盘切异常图标。

### 开机通知
- 先尝试官方通道：等待 Clash 就绪（每 15 秒检测一次，**上限 60 秒**——有 CF 兜底，不必等 5 分钟）；
- 60 秒内 Clash 未就绪，或官方发送失败 → 立即经 CF 通道发送。

### 关机 / 重启通知
- 官方通道短超时（10 秒，不做长时间等待），失败 → 立刻转 CF；
- CF 再失败 → 放弃并记录（关机场景不阻塞关机流程）。

### 手动按钮
「发送开机提醒」「发送关机提醒」两个按钮走同样的自动降级逻辑。

## 3. 配置项（折叠配置区内）

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| Telegram Bot Token | PasswordBox（掩码） | — | 已有 |
| 频道 ID | TextBox | — | 已有 |
| **CF 转发器地址** | TextBox | 空 | 如 `https://xxx.workers.dev/<SECRET>/`；为空表示次级通道未配置 |
| **通道模式** | ComboBox/Radio | 自动 | 自动 / 仅官方直连 / 仅CF转发 |

- CF 转发器地址为空 → 次级通道状态显示「未配置」，自动模式退化为仅官方。
- 程序自动补全末尾 `/`；SECRET 只存配置、掩码显示、不写日志。

## 4. Worker 部署（用户手动，2 分钟）

- 代码文件：`telegram-forwarder-worker.js`（已提供，直接可用）
- 步骤：cloudflare.com → Workers → Create → 粘贴代码 → 把 `SECRET` 改成随机长字符串 → Deploy
- 把 `https://<worker>.workers.dev/<SECRET>/` 填进托盘软件「CF 转发器地址」
- 备选（用户有自有海外服务器）：nginx 反代
  ```nginx
  location /<SECRET>/ {
      proxy_pass https://api.telegram.org/;
      proxy_ssl_server_name on;
  }
  ```

## 5. 状态窗口：通知通道分组

```
通知通道
  当前模式：自动
  官方通道：● 正常 / ○ 未检测 / ● 异常（原因）
  CF 通道：● 正常 / ○ 未配置 / ● 异常（原因）
  上次通知：23:05 经官方直连发送成功
```

- Clash/代理检测保留，**仅作状态展示**，不再是发送的前置阻塞条件。
- 降级发生时，在「上次通知」行明确写出实际走的通道（如 `经CF转发发送成功`）。

## 6. 安全规范（沿用）

- Bot Token、SECRET 掩码显示，不写日志文件，不硬编码在程序里。
- 配置变更即时生效，无需重启。

## 7. 测试清单（交付验收用）

- [ ] 开 Clash → 手动「发送开机提醒」→ 走官方直连，状态显示「经官方直连发送成功」
- [ ] 关 Clash → 手动发送 → 自动降级 CF，Telegram 收到，状态显示「经CF转发发送成功」
- [ ] CF 地址填错且 Clash 关闭 → 发送失败，状态窗口报错，托盘图标切异常
- [ ] 模式切「仅CF」→ 不开 Clash 也能发送
- [ ] 开机：Clash 未启动时，60 秒内经 CF 发出开机通知（不用干等 5 分钟）
- [ ] 关机/重启：官方失败后秒级转 CF 发出
- [ ] CF 地址为空时：通道模式「自动」退化为仅官方，CF 通道显示「未配置」

## 8. 用户手动事项（仅 1 件）

1. 部署 Worker（2 分钟），把地址填进「CF 转发器地址」。
